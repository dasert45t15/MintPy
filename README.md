# MintPy

### Zen-аудиоплеер для Windows: локальная музыка, YouTube-поиск и спокойный интерфейс

MintPy — настольный музыкальный плеер с японской Zen-эстетикой: бумага васи, тушь, винил и лаковые акценты. Он умеет искать музыку на YouTube, воспроизводить локальные файлы и хранить избранное с плейлистами.

## Возможности

- Локальная библиотека: MP3, FLAC, OGG, M4A и WAV, включая считывание метаданных и обложек.
- Поиск и аудиостриминг с YouTube через встроенный `yt-dlp`.
- Домашний экран с большой обложкой, вращающейся виниловой пластинкой и живым таймлайном.
- Светлая, тёмная и системная темы оформления.
- Избранное, плейлисты и очередь воспроизведения.
- Перемотка, регулировка громкости, shuffle/repeat и горячие клавиши.
- Полностью локальное хранение пользовательских настроек и плейлистов.

## Установка

Скачайте актуальную версию на странице [Releases](../../releases):

- `MintPy Setup x.y.z.exe` — установщик с ярлыками в меню «Пуск» и на рабочем столе.
- `MintPy x.y.z.exe` — портативная версия, не требующая установки.

> [!IMPORTANT]
> Установщик **не устанавливает Node.js автоматически**. Для запуска проекта из исходников и самостоятельной сборки установите [Node.js LTS](https://nodejs.org/en/download). Готовый установщик и портативный `.exe` содержат Electron и в обычном сценарии не требуют Node.js отдельно.

После запуска откройте **Library → Import & Scan Folder**, выберите папку с музыкой — MintPy добавит найденные треки в текущую сессию.

## Интерфейс

На Home обложка накладывается на виниловую пластинку. Пластинка вращается только во время воспроизведения, а центральный таймлайн синхронизирован с нижним плеером. Переключение темы доступно в **Settings → Appearance**.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `Space` | Воспроизведение / пауза |
| `←` / `→` | Перемотка на 5 секунд |
| `↑` / `↓` | Громкость ±5% |
| `MediaNextTrack` | Следующий трек |
| `MediaPrevTrack` | Предыдущий трек |

Все сочетания можно изменить в **Settings → Keyboard Shortcuts**.

## Разработка и сборка

1. Установите [Node.js LTS](https://nodejs.org/en/download) (рекомендуется актуальная LTS-версия).
2. Клонируйте репозиторий и установите зависимости:

   ```bash
   npm install
   ```

3. Запустите приложение в режиме разработки:

   ```bash
   npm start
   ```

4. Соберите установщик и портативную версию:

   ```bash
   npm run dist
   ```

Результаты появятся в `dist3/`:

- `MintPy Setup x.y.z.exe`
- `MintPy x.y.z.exe`

## Технологии

- [Electron](https://www.electronjs.org/)
- Vanilla HTML, CSS и JavaScript
- [music-metadata](https://github.com/Borewit/music-metadata) для локальных метаданных
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) для поиска и получения аудиопотока
- [electron-builder](https://www.electron.build/) для Windows-сборок

## Безопасность и приватность

Интерфейс изолирован от Node.js через preload-мост. Локальный аудиосервер слушает только `127.0.0.1`, а доступ к файлам ограничен выбранными музыкальными папками. Данные избранного, плейлистов и настроек сохраняются локально в профиле приложения.
