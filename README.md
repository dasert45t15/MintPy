**MintPy** — это настольный аудиоплеер для Windows, сочетающий медитативную атмосферу с мощными возможностями воспроизведения. Плеер объединяет локальную фонотеку и онлайн-поиск музыки без рекламы, поддерживает импорт плейлистов в один клик из Яндекс Музыки, YouTube и Spotify, оснащён двухдековым аудиодвижком с кроссфейдом, интерактивным питомцем-компаньоном и шестью проработанными до мелочей визуальными мирами.

## Возможности

### 🎵 Звуковой движок и воспроизведение
- **Локальная музыка**: поддержка форматов MP3, FLAC, OGG, M4A и WAV с извлечением встроенных метаданных и обложек высокого разрешения (`music-metadata`).
- **Стриминг с YouTube**: мгновенный онлайн-поиск и аудиопоток через локальный loopback-прокси (`127.0.0.1:3737`) и встроенный `yt-dlp`.
- **Умный резолвер треков (Smart Resolver)**: алгоритм оценки кандидатов с сопоставлением длительности, штрафами за каверы/реакции и приоритетом официальных релизов (`Topic`, `Official Audio`, `VEVO`).
- **Двухдековая архитектура (Dual-Deck WebAudio)**:
  - Плавный бесшовный **кроссфейд** между треками (от 0 до 10 секунд).
  - **Нормализация громкости**: адаптивное RMS-выравнивание с лимитером для защиты от перегрузок и перепадов громкости.
  - **Трёхполосный эквалайзер**: точная настройка басов (Low 250 Гц), средних (Mid 1 кГц) и высоких частот (High 4 кГц).

### 🚀 Перенос музыки (Music Transfer / Playlist Import)
- **Импорт по ссылке в один клик**: просто вставьте публичную ссылку на плейлист или альбом в настройках или окне плейлистов.
- **Яндекс Музыка**: специализированный виртуальный краулер (`VirtualScroll_scroller`), который прокручивает бесконечный виртуальный скроллер страниц и выгружает плейлисты любого масштаба (включая коллекции на **700+ треков**) без потерь и обрезки.
- **YouTube & YouTube Music**: полный парсинг треклистов видео и плейлистов через `yt-dlp`.
- **Spotify**: извлечение названий и исполнителей из открытых веб-страниц альбомов и плейлистов с последующим авто-поиском.

   - *Винил*: концентрический сад камней с гравийными кругами и знаком Энсо.
   - *Таймлайн*: оригинальный стебель бамбука с рельефными сучками и бегунком-листочком.
2. ☕ **Parisian Lo-Fi** (Парижский салон)
   - *Эстетика*: тёплый кофе с молоком, ламповый винтаж, цитаты Вольтера, кассеты.
   - *Винил*: пластинка с кольцами латте-арта и кофейной пенки.
   - *Таймлайн*: латунный желоб цвета карамели, круглые шпульки-метки и ручка из слоновой кости.
3. 🌊 **Deep Ocean** (Океаническая бездна)
   - *Эстетика*: глубоководный батискаф, неоновая гидроакустика и бирюзовое свечение.
   - *Винил*: диск с круговой сеткой эхолота и сонарными волнами.
   - *Таймлайн*: шкала глубиномера, светящиеся импульсы сонара и маяк-бегунок.
4. ⚡ **Synthwave 80s** (Ретровейв / Outrun)
   - *Эстетика*: Майами 80-х, неоновый закат, кибер-пальмы и лазерная сетка.
   - *Винил*: чёрный диск с неоновыми маджента-циановыми дорожками и проволочной сеткой.
   - *Таймлайн*: тёмное кибер-шасси с неоновыми полосками эквалайзера и ромбом-призмой.
5. 🌲 **Boreal Forest** (Хвойный лес)
   - *Эстетика*: сосновый бор, изумрудный мох, туманные поляны и светлячки.
   - *Винил*: спил векового дерева с кольцами роста, мхом и золотистыми искрами.
   - *Таймлайн*: желоб из коры дерева со светящимися спорами светлячков и бутоном.
6. ❄️ **Glass Aurora** (Полярное сияние)
   - *Эстетика*: арктическое матовое стекло, северный ветер и лазурные переливы.
   - *Винил*: космическое стекло с переливами изумрудных и фиолетовых полярных лент.
   - *Таймлайн*: ледяной канал, бриллиантовые ромбы полярных звёзд и кристалл-бегунок.

### 🐾 Интерактивный питомец-компаньон
- **Анимированные компаньоны без фоновых рамок (100% Transparent)**:
  - 🐱 **Bongo Cat** — культовый кот, ритмично отбивающий бит на бонго.
  - 🐕 **Танцующие Сиба-ину** — пара щенков с маракасами и порхающими нотами.
  - 🦆 **Танцующая Уточка** — знаменитая утка на чистом прозрачном фоне с мягкой тенью.
  - 🐼 **Дзен-Панда** — пиксельный панда с веточкой зелёного бамбука.
  - 👻 **Привидение** — парящее дружелюбное привидение в наушниках, закрывающее глазки под музыку.
- **Реактивность к музыке**: питомец танцует, подпрыгивает и покачивается в такт басам через WebAudio FFT Analyser.
- **Пользовательские питомцы**: возможность загрузить собственную картинку или гифку (`.png`, `.webp`, `.gif`), настроить масштаб и перетащить в любую точку экрана.

### ⌨️ Глобальный мут и хоткеи ОС
- **Настоящий Global Mute**: работает по нажатию заданной клавиши (по умолчанию `M` или любая комбинация `Ctrl+M`, `Alt+M`) **даже когда вы находитесь в другой игре, браузере или программе**.
- Защита от троттлинга (`backgroundThrottling: false`) гарантирует моментальное срабатывание и работу звука без задержек при свёрнутом плеере.
- Поддержка мультимедийных клавиш клавиатуры (`MediaPlayPause`, `MediaNextTrack`, `MediaPreviousTrack`).

### 📚 Библиотека, история и поиск
- **Умный поиск**: запоминает последний запрос и сохраняет результаты выдачи при переключении между вкладками.
- **История прослушивания**: до 500 последних треков с возможностью **удаления отдельных ненужных композиций** кнопкой `✕` или полной очистки.
- **Плейлисты и Избранное**: быстрое добавление треков, перестановка и гибкая организация.
- **Резервное копирование**: экспорт и импорт всей базы (настройки, плейлисты, история, питомцы) в единый защищённый JSON-файл.

## Установка

Скачайте сборку на странице [Releases](../../releases):

- **`MintPy Setup 5.3.8.exe`** — полноценный установщик Windows (создаёт ярлыки в меню «Пуск» и на рабочем столе, поддерживает обновление).
- **`MintPy 5.3.8.exe`** — автономная портативная версия (Portable), не требующая прав администратора и установки.
- **`MintPy-v5.3.8.apk`** — мобильная версия для Android смартфонов и планшетов (поддержка Android 7.0–15+, адаптивный мобильный интерфейс, управление на экране блокировки).

> [!NOTE]
> Скомпилированные сборки содержат всё необходимое (включая оптимизированную версию `yt-dlp` и среду выполнения Electron). Установка дополнительного ПО (такого как Python или Node.js) обычным пользователям **не требуется**.

## Горячие клавиши по умолчанию

| Сочетание | Действие | Область действия |
| --- | --- | --- |
| `M` / `Ctrl+M` | **Mute (приглушить / включить звук)** | **Глобально (во всей системе и играх)** |
| `Space` | Воспроизведение / Пауза | Внутри приложения / Media-клавиши |
| `←` / `→` | Перемотка на 5 секунд назад / вперед | Внутри приложения |
| `↑` / `↓` | Изменение громкости на ±5% | Внутри приложения |
| `MediaNextTrack` | Следующий трек | Глобально |
| `MediaPrevTrack` | Предыдущий трек | Глобально |

*Любую клавишу можно переназначить в разделе **Settings → Keyboard Shortcuts**.*

## Разработка и сборка

Если вы хотите запустить MintPy из исходного кода или собрать собственный дистрибутив:

1. Установите [Node.js LTS](https://nodejs.org/en/download) (Node 20+).
2. Склонируйте репозиторий и установите зависимости:
   ```powershell
   git clone https://github.com/dasert45t15/MintPy.git
   cd MintPy
   npm install
   ```
   *Скрипт `scripts/fetch-ytdlp.js` автоматически загрузит и проверит контрольную сумму SHA-256 для бинарника `yt-dlp`.*

3. Запустите плеер в режиме разработки:
   ```powershell
   npm start
   ```

4. Проверьте синтаксис и запустите тесты:
   ```powershell
   npm run check
   npm test
   ```

5. Скомпилируйте релиз для Windows:
   ```powershell
   npm run dist
   ```
   *Готовые бинарники будут помещены в папку `releases/`.*

6. Скомпилируйте мобильный APK для Android:
   ```powershell
   npm run build:apk
   ```
   *Готовый подписанный APK-файл `MintPy-v5.3.8.apk` будет создан в папке `releases/`.*

## Архитектура и безопасность

- **Preload Isolation**: рендерер изолирован от прямого доступа к Node.js (`contextIsolation: true`, `sandbox: true`). Доступ к системным операциям осуществляется строго по белому списку через IPC-мост `window.api`.
- **Локальный loopback-прокси**: аудиопотоки транслируются через внутренний HTTP-сервер, привязанный только к адресу `127.0.0.1`, с одноразовыми токенами сессии.
- **Валидация путей**: модули `data-store.js` и `validators.js` проверяют все пути, имена файлов и входящие структуры данных перед сохранением, предотвращая утечки и повреждения профиля.
